# Personal TDEE & Calorie Planning Calculator

## Project Description
The Personal TDEE & Calorie Planning Calculator is a Python-based software application that calculates an individual's estimated Total Daily Energy Expenditure (TDEE) based on personal body measurements, age, sex, and activity level. It also provides tailored calorie targets (for maintenance, weight loss, or weight gain) and macro-nutrient breakdowns to support personal fitness and health goals.

## Purpose of the Application
The purpose of this project is :
1. To provide a clean, reliable, and user-friendly CLI tool for calculating daily caloric and nutritional needs.
2. To serve as a complete, professional software engineering project demonstrating  DevOps practices.
